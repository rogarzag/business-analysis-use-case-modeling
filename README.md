# News Channel Program — UML Use Case Modeling

A practical Business Analysis exercise focused on actor identification, use case analysis, and UML modeling for a live television news program.

## Project overview

This project defines the main interactions involved in producing and broadcasting a prime-time news program. It identifies the people and supporting roles that interact with the system, describes the system's key functions, and represents those interactions in a UML use case diagram.

The work was completed as part of the **IBM Business Analyst Professional Certificate** training.

## Objectives

- Identify the actors involved in the news program.
- Define the main use cases within the system boundary.
- Document how each actor interacts with the system.
- Represent the scope and interactions in a UML use case diagram.

## System scope

The system boundary is **News Channel Program**. The model includes five actors and six use cases:

| Actors | Use cases |
| --- | --- |
| News producer | Create news segment |
| Reporter | Report news live |
| Viewer | View program |
| Technical team | Interact via social media |
| Advertiser | Manage broadcast equipment |
|  | Provide advertisement |

See [Use Case Analysis](use-case-analysis.md) for the actor descriptions, use case definitions, and associations.

## Tools and methods

- **Lucidchart** — use case diagram modeling.
- **Microsoft Word** — analysis and documentation.
- **UML (Unified Modeling Language)** — visual representation of system behavior and scope.
- **GitHub** — project documentation and version control.

## Key takeaway

Use case modeling helps clarify system scope and stakeholder interactions before defining or evaluating a solution. In this example, it makes visible how editorial, technical, audience, and commercial roles contribute to a live news broadcast.
